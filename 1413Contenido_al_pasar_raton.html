Prueba WCAG 1.4.13: Tooltips

Falla 1.4.13

❌ El Tooltip CSS Puro

Pasa el ratón por el botón:

Este tooltip desaparece si intentas mover el ratón hacia aquí para copiar el texto. Además, no puedes cerrarlo con ESC si te tapa algo.

Por qué falla:
1. Si mueves el ratón al texto rojo, desaparece.
2. Si pulsas ESC, no se va.

Cumple 1.4.13

✅ El Tooltip Robusto

Pasa el ratón o usa el tabulador:

¡Hola! Soy persistente.

Puedes mover el ratón sobre mí para copiar este texto.

Tengo un enlace.

Pulsa ESC para cerrarme.

Por qué cumple:
1. Puedes pasar el ratón DEL botón AL tooltip sin que se cierre.
2. Puedes cerrarlo pulsando ESC.
